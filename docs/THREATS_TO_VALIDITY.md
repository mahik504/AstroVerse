# Threats to Validity

This document outlines the known biases and threats to the validity of the AstroVerse experiments.

## 1. Selection Bias
The datasets generated by this pipeline are inherently biased toward targets that TESS has already observed at a 2-minute cadence. Fainter stars or targets observed only in Full Frame Images (FFIs) at 30-minute cadences may have different noise characteristics that the model has not learned.

## 2. Class Imbalance
Exoplanet transits are rare. True datasets are heavily imbalanced (e.g., 1:100 ratio of planets to false positives). If our datasets are artificially balanced (e.g., 50% Positives, 50% Negatives) for training stability, the resulting Precision and AUPRC metrics will be optimistic compared to real-world deployment.

## 3. Sector Bias
TESS observes different hemispheres in different years. If a model is trained exclusively on Sector 1-13 (Southern Hemisphere), it may overfit to the instrumental systematics present during that specific epoch. 

## 4. Observational Cadence
The pipeline assumes a uniform 2-minute cadence interpolation. Mixing 20-second, 2-minute, and 30-minute cadence data into the same input tensor shape without explicit cadence embedding may confuse the temporal models (Transformer/CNN).

## 5. Catalog Incompleteness
The False Positive class contains targets that may actually host undetectable planets (e.g., planets with periods longer than the observation window, or inclinations that don't transit). Thus, the "Negative" class is contaminated with hidden Positives.

## 6. Label Noise
Misclassification in the NASA Exoplanet Archive (e.g., an Eclipsing Binary mistakenly labeled as a Planet Candidate) will force the model to learn incorrect physical heuristics.
